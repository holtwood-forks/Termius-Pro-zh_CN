# 字体许可与来源

本目录字体仅用于本地学习与测试，均以 SIL Open Font License 1.1（OFL-1.1）分发。
完整许可文本见同目录 `OFL-1.1.txt`。`fontlang.py` 会把本文件与 `OFL-1.1.txt`
一并复制到 Termius 的 `ui-process/assets/`，随打包产物分发。

## 再分发注意

- OFL 要求随字体附带版权声明与许可文本；请勿删除本文件或 `OFL-1.1.txt`。
- 修改字体后不得继续使用 Reserved Font Name，除非获得版权方书面许可。
